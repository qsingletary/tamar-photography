# Tamar Photography

Portfolio site for Tamar, a New York photographer. Static HTML, no build step.

- `index.html`: the whole site (views: Work, Index, Info, and one page per series)
- `data.js`: series titles, categories, years and image sizes
- `img/`: photographs, one folder per series; `img/_c/` holds cover thumbnails

Run locally: `python3 -m http.server 8765`, then open http://localhost:8765
